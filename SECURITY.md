# Security reporting

Please report vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/laurenceholt/kanbanana/security/advisories/new).

Include the affected version, a minimal reproduction using fictional data, impact and any proposed fix. Never post API keys, real conversation histories, board exports or sensitive folder paths in an issue. If the private reporting form is unavailable, open a content-free issue requesting a private contact method; do not include vulnerability details.

Security fixes target the latest beta. This is a small independent project without a guaranteed response time or formal support period.

The local reader is read-only. The app intentionally holds sensitive request text and sends selected requests to OpenAI only when summaries are enabled. See PRIVACY.md for the trust boundary, retention and diagnostic handling.
