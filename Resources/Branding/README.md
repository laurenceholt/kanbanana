# Banana mark

Generated using the built-in image-generation tool on 15 September 2026. The transparent PNG is the source asset. The build derives standard macOS icon sizes; the interface fits the image inside the existing 24 × 25 point logo frame and a 16 × 16 point menu-bar frame.

Prompt: Create a single banana logo for a macOS app called kanbanana. Bold black-and-yellow screenprint pop art inspired by the Velvet Underground banana artwork, with an original curved banana silhouette and a few thick inky imperfect black contour marks and dark tip. A single whole unpeeled banana, angled diagonally from bottom left to top right, generous recognizable curve, flat vivid banana yellow, high contrast black edge, no gradients, no face, no lettering, no signature, no album cover, no peel label. Elegant and striking rather than cute. Designed to remain legible as a tiny 18-point menu bar icon. Banana fills the square canvas with a little margin. Actual transparent background and no shadow. Deliver one clean isolated mark.
